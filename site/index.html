Does AI-written code survive real users?

RealityBench asks a model to build a small web app, then opens it in a real browser and does what users do: the server fails, they double-click, they type nonsense, they use a phone.

Kaggle benchmarkWrite-upSource on GitHub

How it scores

OverallOne number from 0 to 100. Happy path is 40% of the weight. Server errors, bad input, double clicks, keyboard-only use and a 375px screen are the other 60%.

What countsText a person can see. A page that replaces fetch or XMLHttpRequest answers itself, and the request never arrives.

One runEach cell is a single run of that model on that task. The same table is on the Kaggle leaderboard.
